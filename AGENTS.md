# Repository Instructions

- When asked to develop a new feature, create a dedicated worktree for it.
- When a feature is finished and approved, merge the worktree into `main` on `origin` and delete the worktree.
- Ask for approval before pushing and deleting after every implementation, providing a short summary of the changes.
- Do not operate more than one worktree at a time.
- Related features may be developed in the same worktree.
- When making changes to the project, always document and manage the version number.
